# AI 视频工作流空间

一个 AI 视频工作流空间：从一句话想法出发，一路走到可发布的成片，整个过程都在这一个空间里完成。

> 注意：这个空间本身运行在 Muse 里（侧边栏打开），不是一个公开网页。本仓库放的是空间的数据和设计说明：提示词库数据 + 五个区的用法。空间的实时版本在 Muse 的侧边栏里。

## 五个区

1. **灵感与提示词库**：204 条 Muse Video 提示词，可搜索、按 13 类筛选，每条带作者和原帖链接，一键复制。数据来自 GitHub 仓库 [apimodels/muse-video-prompts](https://github.com/apimodels/muse-video-prompts)，每天早上自动同步一次。另有模板句式区（镜头简报、运动模式、视听工作流）。
2. **策划台**：按 8 阶段管线走（想法 → 剧本 → 分镜 → 美术方向 → 提示词）。输入一句话，输出分镜表，每镜含画面、镜头运动、时长、提示词、配音和字幕；可改镜保存，可导出 Markdown。沉淀了 38 个标杆案例的技法要点。
3. **节点画布**：在画布上拖拽连接提示词节点、图片节点、生成节点，带时间线编辑器，能把多个片段按顺序拼起来，预览成片结构，导出 MP4 结构清单。
4. **批量与导演台**：批量跑提示词，一次多条，队列显示进度。导演编译器把同一条创意编译成 Muse Video、Veo、Kling、Sora、Wan、混元 6 个模型的提示词版本，并注明各模型的时长、画幅、参数差异。
5. **成片区**：一句话成片模式，输入一句话，自动走脚本、关键帧、分镜、字幕全套流程，输出成片 MP4 任务单；本地优先模式，看板式分镜管理，配合 ComfyUI 出图出视频的任务清单。

## 用法

1. 去提示词库搜一个顺眼的，复制走。
2. 去策划台输一句话，出一张分镜表，改一镜再保存。
3. 去导演台选个模型，复制那个版本的英文提示词去生视频。
4. 去成片区拿任务单，按清单一段段生，再拼起来。

## 数据

- `prompts.json`：204 条 Muse Video 提示词的完整数据（标题、分类、作者、原帖链接、提示词全文），同步自 [apimodels/muse-video-prompts](https://github.com/apimodels/muse-video-prompts)。

## 说明

空间里只做策划、提示词、流程管理与任务单，不假装真的能调用视频模型生成。生成步骤留的是去 Muse Video / 对应模型执行的入口和复制按钮，视频要去对应平台上生。
